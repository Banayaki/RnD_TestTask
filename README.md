# RnD_TestTask

Тестовое задание для собеседования на позицию разработчика в RnD-команду.

Срок — **три рабочих дня**. Результат: работающий сервис, записка `NOTES.md` и короткое демо.

## Состав репозитория

- `TZ.md` — постановка задачи, требования к интерфейсу, демо и записке.
- `materials/` — выгрузки клиентов и коммуникаций, описание расчёта, пример для ручного ввода.

С этого файла достаточно перейти к `TZ.md` и прочитать его целиком, затем `materials/scoring.md`.

## Требования к среде

- Python 3.10 или новее
- один веб-интерфейс: FastAPI + HTML либо Streamlit
- отдельный фронтенд на React не нужен

Ассистенты при написании кода допустимы. На защите нужно самостоятельно объяснить расчёт и внести правку в код.

Решение присылайте отдельным репозиторием или архивом: код, `README` с запуском, `.env.example`, `NOTES.md`.
